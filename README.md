\# Express.js Practice Projects



\## About This Repository



This repository contains my Express.js learning exercises and practical projects developed during my Full Stack Development training.



It includes backend development concepts, authentication, database operations, file uploads, and integration with frontend applications.



\## Technologies Used



\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- React.js

\- HTML, CSS, JavaScript

\- JSON Web Token (JWT)



\## Projects Included



| Folder | Description |

|---|---|

| Basics | Express.js fundamentals and basic server operations |

| CRED | Create, Read, Edit and Delete operations |

| Express\_Cred\_Exam | Express CRUD practice |

| JWT | Token-based authentication |

| Multer | File and image uploads |

| cookie | Cookie handling |

| google\_auth | Google authentication integration |

| lms\_react\_express | React and Express integration |

| nodeMailer | Email functionality using Node.js |

| passport JS | Authentication using Passport.js |

| server | Backend server and user management |



\## How to Run



1\. Open the required project folder.

2\. Install dependencies using `npm install`.

3\. Check the `package.json` file for the available scripts.

4\. Run the appropriate script to start the project.
